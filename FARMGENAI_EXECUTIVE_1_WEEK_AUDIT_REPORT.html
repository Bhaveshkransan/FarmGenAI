🏛️ Architectural Invariants Enforced

1. Authoritative Farmer Deal Gate

The system enforces: NO VALID FARMER DEAL = NO DOWNSTREAM EXECUTION. The gate checks PostgreSQL negotiations records directly (status must strictly be DEAL or COMPLETED with positive price and volume). Client-side flags, LLM assertions, and URL states are untrusted.

2. Real Transport LangGraph Integration

When "Proceed to Transport Agent" is clicked, it invokes POST /requirements/{id}/workflow/step which calls run_transport_workflow(). This executes the real 11-node Transport LangGraph StateGraph, selects vehicles from the database, calculates highway distances and tolls, and writes the plan into Buyer memory.

3. Context Isolation (Zero Data Leakage)

Downstream transport receives only minimal logistics metadata: crop, quantity_kg, pickup, delivery, deadline, refrigerated_required. Private farmer counter-bids, maximum budgets, and negotiation transcripts are strictly omitted.

4. Economic Landed Cost Modeling

Suppliers are evaluated by True Landed Cost ($P_{\text{base}} + \text{freight} + \text{APMC cess}$). A closer farmer with a higher base price wins over a distant farmer with a lower base price if the freight advantage is economically superior.
